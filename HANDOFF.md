## Context for Resuming Agent

### Important Context
- **TokenStream Design:** The stream uses `Emit()` which handles trivia (comments) by attaching them to the next token, while `EmitRaw()` emits them as tokens.
- **Keyword Resolution:** `lookupKeyword` in `lexer.go` uses `TokenTypeString(upper)` (generated by `enumer`). Since there is no `END` token (only `END_BLOCK`), the string `"end"` defaults to `IDENTIFIER`.
- **Black-Box Requirement:** The user explicitly requested to treat the `TokenStream` as a black box for testing.

### Potential Gotchas
- The `enumer` generated file `pkg/tokenizer/tokentype_enumer.go` is ignored by git/gemini-ignore but contains the critical mapping for keywords.
- `ReadBlock` assumes end markers are at the start of a line.
